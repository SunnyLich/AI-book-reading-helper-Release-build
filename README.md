AI Book Reading Helper

AI-powered desktop tool that assists with reading by detecting and explaining keywords directly inside your text.

This is the Windows release build of the application.

Features

Local AI-powered keyword detection

Inline explanations for selected text

Desktop experience (Electron-based)

Offline-friendly architecture

Clean and distraction-free reading workflow

Download

Go to the Releases section of this repository.

Download the latest .zip file.

Extract the folder.

Run:

AI book reading helper.exe

System Requirements

Windows 10 / 11 (64-bit)

x64 architecture

Notes

This is an early release and may contain bugs.

Windows SmartScreen may show a warning because the app is not code-signed. Click More info → Run anyway if you trust the download.

The application is distributed as-is.
